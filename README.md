# دستیار هوشمند محمد پاتریک (Mohammad Patrick Android Assistant)

پروژه بومی اندروید (Native Android) به زبان کاتلین (Kotlin) و Jetpack Compose، طراحی و بهینه‌سازی شده برای گوشی **سامسونگ گلکسی A23** و سیستم‌عامل **اندروید ۱۴ (One UI 6)**.

---

## ۱. ویژگی‌ها و ماژول‌های پیاده‌سازی شده

- **ورود و قفل امن (Security Lock):** ذخیره‌سازی رمز عبور با سالت تصادفی و هش رمزنگاری‌شده AES-256 در Keystore / EncryptedSharedPreferences، پشتیبانی از قفل خودکار و احراز هویت بیومتریک (اثر انگشت).
- **داشبورد وضعیت واقعی (Real-time Dashboard):** نمایش وضعیت واقعی سرویس میکروفون، وضعیت سرویس پس‌زمینه «سلام پاتریک»، وضعیت اتصال API و دسترسی سریع به ابزارهای سیستمی.
- **گفتگوی متنی محلی (Text Chat):** تاریخچه کامل گفتگوها در پایگاه داده داخلی Room، مدیریت گفتگوها (ایجاد، تغییر نام، حذف)، کپی و حذف پیام‌ها، انتخاب عکس و فایل، با نمایش شفاف پیام راهنمای اتصال API: «برای دریافت پاسخ هوشمند، ابتدا API خود را متصل کنید.» بدون تولید پاسخ‌های ساختگی یا فیک.
- **مکالمه صوتی و عبارت بیداربش («سلام پاتریک»):** تبدیل گفتار فارسی به نوشتار با `SpeechRecognizer`، متن صوتی قابل ویرایش، موتور خواندن صوتی پاسخ‌ها (TTS)، تنظیم سرعت گفتار و کنترل اجرای سرویس پس‌زمینه.
- **سرویس پیش‌زمینه اندروید ۱۴ (Foreground Service):** پیاده‌سازی سرویس با تایپ قانونی `foregroundServiceType="microphone"` به همراه اعلان دائمی با دکمه‌های کنترل فوری و توقف سرویس.
- **حافظه محلی (Local Memory):** ثبت اولویت‌ها، دستورالعمل‌ها و یادداشت‌های کاربر در دیتابیس Room با قابلیت جستجو، ویرایش، حذف، سنجاق و خروجی گرفتن متنی (JSON). داده‌ها به هیچ سروری ارسال نمی‌شوند.
- **یادآورها و هشدارها (Reminders):** زمان‌بندی دقیق کارهای محلی با `WorkManager` و ثبت در دیتابیس، بازیابی و زمان‌بندی مجدد خودکار پس از روشن شدن یا راه‌اندازی مجدد گوشی (`BootCompletedReceiver`).
- **راهنمای راه‌اندازی و دسترسی‌ها (Permission Setup Wizard):** بررسی دقیق و زنده دسترسی‌های میکروفون، اعلان‌ها و معافیت باتری، با دکمه باز کردن تنظیمات رسمی سیستم و بررسی مجدد هنگام بازگشت به برنامه.
- **راهنمای تخصصی سامسونگ گلکسی A23:** آموزش گام‌به‌گام و اینتنت‌های مستقیم برای تنظیم حالت باتری روی **Unrestricted** (نامحدود) و اضافه کردن برنامه به **Never sleeping apps** در رابط کاربری One UI سامسونگ.
- **معماری تمیز برای اتصال سرور آینده (Clean API Layer):** تعریف کامل اینترفیس‌های `AssistantRepository`، `ApiClientProvider`، `AssistantApiService` با پایش وضعیت شبکه و بدون هیچ‌گونه کلید یا وابستگی به سرور در این فاز.

## ۲. نحوه ساخت خودکار فایل APK بدون نیاز به نصب اندروید استودیو (از طریق GitHub Actions)

این پروژه مجهز به یک ورک‌فلو آماده گیت‌هاب اکشن در مسیر `.github/workflows/build-apk.yml` است که به طور خودکار کدها را کامپایل کرده، تست‌های واحد را اجرا می‌کند و فایل خروجی APK را می‌سازد.

### مراحل دریافت APK:
1. پوشه سورس کد را در یک مخزن جدید در حساب گیت‌هاب خود پوش (Push) کنید:
   ```bash
   git init
   git add .
   git commit -m "Initial commit - Mohammad Patrick Android Assistant"
   git branch -M main
   git remote add origin https://github.com/USERNAME/mohammad-patrick-assistant.git
   git push -u origin main
   ```
2. وارد مخزن خود در سایت GitHub شوید و به تب **Actions** بروید.
3. ورک‌فلو با نام **Build Mohammad Patrick Android APK** به طور خودکار شروع به اجرا می‌کند (یا می‌توانید به صورت دستی از دکمه Run workflow آن را اجرا کنید).
4. پس از اتمام اجرا (علامت تیک سبز)، روی اجرای مربوطه کلیک کنید.
5. در انتهای صفحه در بخش **Artifacts**، فایل **MohammadPatrick-Debug-APK** را دانلود کنید.
6. فایل ZIP دانلود شده را باز کنید؛ فایل `app-debug.apk` آماده نصب روی گوشی سامسونگ گلکسی A23 شماست!

## ۳. تنظیمات حیاتی روی گوشی سامسونگ گلکسی A23

سامسونگ به طور پیش‌فرض برای صرفه‌جویی باتری، برنامه‌های پس‌زمینه را متوقف می‌کند. برای کارکرد پیوسته عبارت «سلام پاتریک»:
1. وارد **تنظیمات گوشی (Settings)** > **برنامه‌ها (Apps)** > **محمد پاتریک** شوید.
2. به بخش **باتری (Battery)** رفته و گزینه **نامحدود (Unrestricted)** را انتخاب کنید.
3. در مسیر **مراقبت از دستگاه (Device Care)** > **باتری (Battery)** > **محدودیت‌های استفاده در پس‌زمینه (Background usage limits)**، دکمه **برنامه‌های هرگز به خواب نرود (Never sleeping apps)** را بزنید و محمد پاتریک را اضافه کنید.
4. دسترسی **اعلان‌ها (Notifications)** را در حالت مجاز قرار دهید.

## ۴. مشخصات قرارداد سرور آینده (API Contract)

هنگامی که سرور خود را راه‌اندازی کردید، در بخش تنظیمات برنامه آدرس Base URL را وارد کنید. برنامه درخواست‌های زیر را ارسال می‌کند:

- **متد:** `POST /chat/completions`
- **ساختار داده ورودی (Request Body):**
  ```json
  {
    "conversation_id": "uuid-here",
    "prompt": "متن ورودی کاربر",
    "image_base64": null,
    "file_context": null,
    "device_info": {
      "device": "Samsung Galaxy A23",
      "os_version": "Android 14 (API 34)",
      "locale": "fa-IR"
    }
  }
  ```
- **ساختار پاسخ مورد انتظار (Response Body):**
  ```json
  {
    "reply": "پاسخ متنی هوش مصنوعی به کاربر",
    "finish_reason": "stop",
    "usage_tokens": 42
  }
  ```

همچنین متد `POST /chat/stream` با قالب Server-Sent Events (SSE) برای استریم زنده کلمات پشتیبانی می‌شود.
